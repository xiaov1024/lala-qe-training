1. 学生能识别 6 大机加工工艺的常见质量问题

3. 学生能跑 SPC + FMEA + MSA + APQP/PPAP + IATF 16949
4. 老师傅隐性经验外化(听声音/手感/直觉 → 可学)
5. 双技能人才(机 + 质)1-3 年 8-15K,5-10 年 25-50K
